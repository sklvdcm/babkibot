# Babki

Закрытый веб-интерфейс для истории расходов и месячных лимитов. Новые траты добавляются через Apple Shortcuts, вызванную Action Button на iPhone. История, исправления, удаление расходов, категории и лимиты доступны только на сайте после ввода пароля.

## Что работает

- получение категорий и запись расхода из iPhone Shortcut;
- защита Shortcut API персональными bearer-токенами и ключом идемпотентности;
- обзор остатка на месяц и прогресса по категориям;
- полная история с фильтрами по месяцу и категории;
- изменение суммы, категории и времени расхода;
- удаление ошибочной записи с подтверждением;
- создание, переименование и отключение категорий;
- отдельный лимит категории на каждый месяц;
- вход по серверному паролю, подписанная `HttpOnly`-cookie, CSRF-защита и ограничение попыток входа.

## Настройка сервера

1. Скопируйте `.env.example` в `.env`.
2. Задайте случайный пароль PostgreSQL в `POSTGRES_PASSWORD` и тот же пароль в `DATABASE_URL`.
3. Добавьте персональные значения в `SHORTCUT_TOKENS`. Токен должен быть не короче 32 символов.
4. Задайте `WEB_PASSWORD` и случайный `WEB_SESSION_SECRET`, например результат `openssl rand -hex 32`.
5. Запустите `docker compose up -d --build`.
6. Проверьте `curl http://127.0.0.1:8000/health`.

Реальные пароли и токены должны находиться только в серверном `.env` с правами `600`. Файл исключён из Git и Docker build context.

## API для iPhone Shortcut

Сначала Shortcut получает категории:

```http
GET /api/v1/categories
Authorization: Bearer <персональный токен>
```

После подтверждения суммы и категории отправляет расход:

```http
POST /api/v1/expenses
Authorization: Bearer <персональный токен>
Content-Type: application/json

{
  "amount": 1500,
  "category_id": 1,
  "idempotency_key": "случайный UUID для этого запуска"
}
```

`idempotency_key` не позволяет повторному HTTP-запросу создать две одинаковые траты.


Интерфейс использует шрифты, цветовые и layout-токены, а также SVG-иконки из [mishanaer/deslop](https://github.com/mishanaer/deslop/tree/main/primitives).
